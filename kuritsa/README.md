# Курица-повелительница (в разработке)

Отдельный мод для Minecraft Java 1.20.1 + Forge. Убей 10 кур — и придёт Она.

**Этап 1 из 7:** счётчик убитых кур, сообщения, появление огромной курицы, команды.

⬇️ [kuritsa-1.20.1-forge-etap1.jar](https://github.com/abodubalay/claude-mod/raw/main/kuritsa/kuritsa-1.20.1-forge-etap1.jar)

Команды (нужны читы): `/kuritsa spawn`, `/kuritsa dance`, `/kuritsa count`, `/kuritsa reset`.
