# Курица-повелительница (в разработке)

Отдельный мод для Minecraft Java 1.20.1 + Forge. Убей 10 кур — и придёт Она.

**Этап 2 из 7:** счётчик кур, появление, своя модель с короной и очками, вступительный танец, полоска здоровья.

⬇️ [kuritsa-1.20.1-forge-etap2.jar](https://github.com/abodubalay/claude-mod/raw/main/kuritsa/kuritsa-1.20.1-forge-etap2.jar)

Команды (нужны читы): `/kuritsa spawn`, `/kuritsa dance`, `/kuritsa count`, `/kuritsa reset`.
