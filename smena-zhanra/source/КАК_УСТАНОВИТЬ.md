# Мод «Смена жанра» 🎭 — как установить и проверить

Minecraft Java **1.20.1** + **Forge 47.x** (подойдёт любая версия Forge для 1.20.1, начиная с 47.0).

## 1. Установка (5 минут)

1. Установи Forge для 1.20.1, если его ещё нет: сайт `files.minecraftforge.net` → версия 1.20.1 →
   «Installer» → запусти скачанный файл → «Install client».
2. Открой папку игры:
   - Windows: нажми `Win + R`, введи `%appdata%\.minecraft` и нажми Enter;
   - macOS: `~/Library/Application Support/minecraft`;
   - Linux: `~/.minecraft`.
3. Если внутри нет папки `mods` — создай её.
4. Положи в `mods` файл **`smena-zhanra-1.20.1-1.0.0.jar`**. Твои другие моды остаются там же — мод с ними совместим.
5. Запусти лаунчер, выбери профиль **forge 1.20.1** и нажми «Играть».
6. В списке «Моды» в главном меню должен появиться мод «Смена жанра».

Для сервера: тот же `.jar` кладётся в папку `mods` сервера **и** каждому игроку (экраны мини-игр рисуются у игрока).

## 2. Быстрая проверка (с читами)

Создай мир с разрешёнными читами (или открой мир для сети с читами) и вводи команды в чат:

| Команда | Что произойдёт |
|---|---|
| `/zhanr start novella` | Визуальная новелла «Свинья моей мечты» |
| `/zhanr start sud` | Суд «Крипер против тебя» |
| `/zhanr start ritm` | Ритм-игра «Копай в такт» (клавиши D F J K) |
| `/zhanr start viktorina` | Викторина «Кто хочет стать изумрудным миллионером» |
| `/zhanr start fighting` | Файтинг «Куриный Комбат» |
| `/zhanr random` | Случайный жанр |
| `/zhanr off` / `/zhanr on` | Выключить / включить автоматическую смену |
| `/zhanr start sud ИмяИгрока` | Запустить жанр другому игроку |

Без команд жанр меняется сам — каждые 20 минут игры.

## 3. Что проверить в игре

- [ ] За 5 секунд до смены экран покрывается помехами, большая надпись «СМЕНА ЖАНРА... 5... 4...», звук переключения каналов.
- [ ] Открывается отдельный экран мини-игры со своей музыкой из нотных блоков.
- [ ] Во время мини-игры тебя не бьют мобы, а мобы вокруг (32 блока) стоят замороженные. После игры они снова двигаются.
- [ ] После конца — помехи и надпись «ВОЗВРАТ В MINECRAFT», в чате пишется результат.
- [ ] Esc во время мини-игры → в чате «Трус сбежал из жанра!», следующая смена придёт через 5 минут.
- [ ] Новелла: хорошая концовка → рядом Свинка-тян с бантиком, ходит за тобой, её нельзя убить. Плохая → свиньи убегают от тебя (неделю игрового времени).
- [ ] Суд: если оправдали — конфетти и изумруды. Если виновен — одно из наказаний на игровой день: розовая броня (твоя броня вернётся потом), кудахтающие курицы-преследователи или надпись «ПРЕСТУПНИК» над головой.
- [ ] Ритм: при хорошей игре в инвентаре алмазы, золото, железо, уголь — сколько поймал; при плохой — булыжник и «Ритма нет — копай руками».
- [ ] Викторина: изумруды 1 → 2 → 5 → 10 → 25, подсказки работают, можно «Забрать» выигрыш.
- [ ] Файтинг: при победе «БЕЗУПРЕЧНАЯ ПОБЕДА» и награда; при поражении противник танцует над тобой.
- [ ] В мультиплеере: над игроком в мини-игре — мерцающий телевизор и надпись «[ник] сейчас в другом жанре».

## 4. Настройки

После первого запуска появится файл `config/smenazhanra-common.toml` (в папке игры или сервера). Открой его Блокнотом:

- `intervalMinutes = 20` — как часто меняется жанр (минут);
- `cowardNextShiftMinutes = 5` — через сколько придёт смена после побега по Esc;
- `novella / sud / ritm / viktorina / fighting = true` — поставь `false`, чтобы выключить жанр;
- `storySeconds = 120` — максимум времени для новеллы, суда и викторины;
- `rhythmSeconds = 60`, `fightSeconds = 60` — длительность ритм-игры и раунда файтинга;
- `allowEscSkip = true` — можно ли сбегать по Esc.

Сохрани файл и перезапусти мир.

## 5. Управление в мини-играх

- **Новелла, суд:** мышь (клик — дальше / выбрать), клавиши 1–3 (1–4 в суде), пробел — дальше.
- **Ритм:** D, F, J, K.
- **Викторина:** мышь или клавиши 1–4.
- **Файтинг:** A/D — ходить, W — прыжок, J — удар, K — блок (держать), J+K — суперприём (когда шкала «СУПЕР» заполнена).
- Клавиши работают по расположению на клавиатуре, раскладку (русская/английская) переключать не нужно.

## 6. Как собрать мод заново (если захочешь что-то поменять)

Нужна Java 17. В папке проекта выполни `gradlew build` (Windows) или `./gradlew build` (macOS/Linux).
Готовый файл появится в `build/libs/`.
Картинки перерисовываются скриптом `tools/draw_art.py`, звуки — `tools/make_sounds.py` (нужны Python, Pillow, numpy, ffmpeg).
