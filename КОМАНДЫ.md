# Все команды модов

## 🤖 Напарник (Claude, DeepSeek, Grok, ChatGPT, Gemini)
Вместо `<нейросеть>`: `claude`, `deepseek`, `grok`, `chatgpt`, `gemini` или id своей.

| Команда | Что делает |
|---|---|
| `/claude` | справка |
| `/claude key <нейросеть> <ключ>` | задать ключ (виден только тебе) |
| `/claude key <нейросеть> remove` | удалить ключ |
| `/claude url <нейросеть> https://...` | адрес сервера (`reset` — стандартный) |
| `/claude model <нейросеть> <модель>` | сменить модель |
| `/claude names <нейросеть> имя1, имя2` | на какие слова откликается |
| `/claude new <id> <Имя>` | добавить свою нейросеть |
| `/claude list` | все нейросети: ключ, сервер, модель |
| `/claude summon <нейросеть>` | призвать себе |
| `/claude summon <нейросеть> <ник>` | призвать для другого игрока |
| `/claude inv [нейросеть]` | инвентарь своего бота |
| `/claude transfer <нейросеть> <ник>` | передать бота другому |
| `/claude stop` | остановить всех |
| `/claude dismiss [нейросеть]` | отпустить (вещи выпадут) |
| `/claude mode all` / `mention` | если никого не назвали: отвечают все / никто |
| `/claude effort low` / `medium` / `high` | насколько глубоко думает Claude |
| `/claude skin` | применить свои скины |

Без команд: пиши в чат «клод, …», «дипсик, …», «грок, …»; «стоп» — остановить; ПКМ по боту — инвентарь.
