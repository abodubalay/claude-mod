# Кино 🎬📺

Мод для **Minecraft Java 1.20.1 + Forge 47+**. Редкие эпичные кат-сцены после обычных действий, закадровый смех ситкома и титры в конце «серии». Ничего не мешает играть: всё редко, коротко и пропускается любой клавишей. Задание — в [TZ.md](TZ.md).

⬇️ **[kino-1.20.1-forge-1.0.0.jar](https://github.com/abodubalay/claude-mod/raw/main/kino/kino-1.20.1-forge-1.0.0.jar)** — положи в папку `mods`.

Команды (с читами): `/kino scene` · `/kino laugh` · `/kino credits` · `/kino off` · `/kino on`.
Конфиг: `config/kino-common.toml` (паузы, шанс, частота титров, громкость, включение по отдельности).
