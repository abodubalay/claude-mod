# Кит смотрит 🐋🎀

Мод для **Minecraft Java 1.20.1 + Forge 47+**. Огромный летающий кит-цундере в костюме горничной: незаметно висит над тобой и смотрит… пока ты не посмотришь на него. Никому не вредит и ничего не ломает. Работает вместе с модом-напарником и Курицей-повелительницей.

⬇️ **[kit-smotrit-1.20.1-forge-1.0.0.jar](https://github.com/abodubalay/claude-mod/raw/main/kit/kit-smotrit-1.20.1-forge-1.0.0.jar)** — положи в папку `mods`.

## Что умеет
- Раз в минуту шанс 5% (+1% за очко симпатии, максимум 20%), только под открытым небом. Проявляется в 25–30 блоках над тобой с тихим пением.
- Длиной ~20 блоков, в костюме горничной: кружевной ободок, бантик, фартук с оборками, манжеты. Покачивается, следит за тобой головой, моргает, плывёт следом. Небо темнеет, музыка игры затихает, курицы и коровы задирают головы.
- Посмотри на него 3 секунды — смутится: глаза расширятся, покраснеет, сердечки и пар, фраза в чат, закроется плавником и удерёт вверх.
- Не смотришь — через 30–60 с уплывёт сам: «...Я ещё вернусь. Н-не потому что хочу!»
- Клик левой кнопкой по киту (смотря на него) — «Ч-что ты делаешь, идиот?!», симпатия −1.
- ПКМ цветком, пока кит рядом — краснеет до фиолетового, роняет тортик, симпатия +1.
- Симпатия: Незнакомец (0–2) → Знакомый (3–5) → Друг (6–9, иногда роняет еду) → Лучший друг (10+, машет плавником).

## Команды (нужны читы)
`/kit spawn` · `/kit off` · `/kit on` · `/kit simpatia` · `/kit simpatia set <число>` · `/kit reset`

baseChance, checkIntervalSeconds, maxChance, stayMinSeconds, stayMaxSeconds, stayMaxTotalSeconds, gazeSeconds, whaleScale, sound, skyDarkening, chatMessages.
